## 🧠 Design Philosophy

Three principles guide every decision in this project.

**First, respect the source.** StreamVault Archivist is a tool for personal retention, not for redistribution. The documentation consistently reminds users to honor copyright, terms of service, and the rights of creators. The software does not remove watermarks, bypass paywalls, or circumvent authentication.

**Second, respect the user.** Every dialog, every button label, every error message is written with the assumption that the person reading it is intelligent but not necessarily technical. Jargon is explained. Failure states suggest next steps. The application never blames the user.

**Third, respect the machine.** Efficient memory use, graceful degradation on older hardware, and a small installation footprint mean that StreamVault Archivist runs comfortably on Windows 10 machines from 2018 as well as brand-new Windows 11 workstations.
